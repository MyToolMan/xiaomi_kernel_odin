PERFORMANCE

DEFAULT / DAILY TUNING

将现有 CPU/GPU OPP 提升到硬件上限，并持续压制系统回写。

EXTREME

738 MHz GPU FLOOR / WATCHDOG ACTIVE

在 PERFORMANCE 基础上把 GPU 下限提升到 738 MHz，适合录制和高负载游戏，空闲功耗会上升。

BENCHMARK

HIGH RISK / THERMAL WATCHDOG ACTIVE

提高最低频率并锁定 GPU 下限，只适合短时压力测试。

SAFE / COOLING

REDUCED FREQUENCY CEILING

恢复安全频率上限并提高 GPU 冷却约束，适合高温环境。
